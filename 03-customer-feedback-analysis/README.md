# Assistente di analisi feedback cliente

Progetto applicativo realizzato durante il Master in AI Automation
presso ProfessionAI.

## Obiettivo
Trasformare feedback non strutturati in temi, sintesi e proposte
di priorità, mantenendo la supervisione umana.

## Soluzione
Sequenza di prompt per:
- Estrarre citazioni dai feedback.
- Classificare i temi.
- Generare sintesi.
- Proporre priorità di intervento.

## Materiali
- Documento_Finale.docx: panoramica del progetto.
- Design Document_v3.txt: versione finale dei prompt.
- Dataset_60_feedback.txt: dataset di feedback sintetici.
- Output_v1.txt, Output_v2.txt e Output_v3.txt: output delle iterazioni.

Gli altri documenti descrivono la valutazione delle attività,
le scelte progettuali e il confronto tra modelli.

## Limiti
Progetto didattico con dati sintetici. Le proposte richiedono
valutazione umana; le prestazioni nell’uso operativo
richiedono ulteriori verifiche.
